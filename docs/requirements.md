# Coffee Ordering System — Requirements Specification

## 1. Функциональ шаардлагууд

### REQ-001: Хэрэглэгч бүртгүүлэх
Систем нь шинэ хэрэглэгчийг email + password ашиглан бүртгэх боломжтой байна.

### REQ-002: Хэрэглэгч нэвтрэх
JWT ашиглан аюулгүй байдлаар нэвтрэх боломжтой байна.

### REQ-003: Меню жагсаалт авах
Хэрэглэгч системийн кофены менюг харах боломжтой.

### REQ-004: Сагсанд бараа нэмэх
Хэрэглэгч барааг сонгон сагсанд нэмнэ.

### REQ-005: Захиалга үүсгэх
Хэрэглэгч сагснаас төлбөрт оруулж захиалга үүсгэнэ.

### REQ-006: Захиалгын төлөв шалгах
Хэрэглэгч өөрийн захиалгын төлвийг харна.

### REQ-007: Админ — Меню CRUD
Админ барааг нэмэх/засах/устгах боломжтой.

### REQ-008: Админ — Захиалга удирдах
Админ захиалгын статус өөрчлөх боломжтой.

---

## 2. Функциональ бус шаардлагууд

### NFR-001: Найдвартай байдал
Систем 99% uptime хангана.

### NFR-002: Хүртээмж
Бүх төхөөрөмж дээр 3 секундээс бага хугацаанд меню ачаалах.

### NFR-003: Аюулгүй байдал
Паролыг bcrypt + JWT authentication ашиглана.

### NFR-004: Гүйцэтгэл
API хариу ≤ 500ms байх.

### NFR-005: Хэмжээнээс үл хамаарах чадвар
Систем 1000 зэрэгцээ хэрэглэгчийг даах.
